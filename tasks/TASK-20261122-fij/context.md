## Patterns to Follow
- **Guarded CommonJS Exports for Classic MV3 Scripts (`LESSON-001`):** See `background.js:667-690`, `content.js:347-375`, `popup.js:386-400` — Guard browser globals (`typeof document !== "undefined"`, `typeof chrome !== "undefined"`), gate auto-init behind `typeof module === "undefined"`, and export pure helpers via `if (typeof module !== "undefined" && module.exports)` for `node --test`.
- **Prototype-Safe Plain Object Access (`BUG-006`):** See `background.js:385, 399, 469, 555` — Guard every dynamic lookup on `series` maps with `Object.hasOwn(obj, key)` and reject `"__proto__"`, `"constructor"`, `"prototype"` (including after `.toLowerCase().trim()`).
- **Safe DOM Creation & Sub-10ms Cache Render:** See `popup.js:82-146` and `loadVault()` (`popup.js:298-322`) — Construct card elements with `document.createElement` + `.textContent` (avoid interpolating user/scraped strings into `innerHTML`), and read `chrome.storage.local` immediately on open before `SYNC_VAULT`.
- **Queued Background Test Flushing:** See `test/background.test.js:894, 1666` — Invoke `handleMessage(...)` and await `enqueueOperation(async () => {})` to deterministically drain serialized async storage/fetch operations before asserting.
- **Standalone Classic Script Boundary:** See `manifest.json:21-37` and `popup.html:286` — Extension scripts (`background.js`, `content.js`, `popup.js`) load independently without a bundler or ES module loader; keep helpers local to each entry script (or loaded explicitly if ever shared in `popup.html`) rather than adding `import`/`export`.

## Anti-Patterns Flagged
- `background.js` lines 79–87 (`isValidMangaName`): Checks `trimmed === "__proto__" || trimmed === "constructor" || trimmed === "prototype"` without `.toLowerCase()` — `"__PROTO__"` passes validation and normalizes to `"__proto__"`.
- `background.js` lines 387–391 & 484–488: Overwrites series entries as `{ chapter, url, updated }`, silently dropping `site` (despite `liveMutation.payload.site` at line 497) and `title`.
- `background.js` lines 366–374 (`reconcileAndSync` empty-queue branch): Directly overwrites local `storage.series` with `remoteVault.series` without running legacy migration or local-vs-remote LWW reconciliation.
- `popup.js` lines 35, 38–39, 190–191, 274–275, 358, 361: Uses `innerHTML = ...` and loop-body `listElement.appendChild(card)` (line 202) instead of `DocumentFragment` + `replaceChildren()`.
- `popup.js` lines 148–167 & 170–200: Attaches per-card `mouseenter`/`mousemove`/`mouseleave` and `click` listeners inside `renderList()`, plus adds dead `.no-cover` class and reads removed `#manga-preview`/`#preview-img` (`lines 6-7, 332-340`).
- `popup.js` lines 89, 223–225, 261–263, 307: Displays and searches/sorts solely by object key (`name` / `a[0]`) instead of `info.title || key`, and hardcodes alphabetical sort instead of configurable Recently Read vs A–Z.
- `popup.js` lines 173, 183, 194: Sets `this.innerText = "Deleting..."` / `"Error"` directly on `.btn-delete` (wiping its `<img src="trash.svg">` icon child); under event delegation, target `deleteBtn` explicitly (`e.target.closest(".btn-delete")`) and guard against repeat clicks.
- `popup.html` lines 159–161, 169–180, 283–285: Retains dead `.no-cover`, `#manga-preview`, and `#preview-img` CSS/markup, and lacks the `kunmanga` radio in `#filter-container` (lines 263–275) and sort toggle in `#header` (lines 244–256).
- `test/popup.test.js` lines 64–65, 73–74, 350, 353: Mock DOM registers removed `#manga-preview`/`#preview-img`, lacks `createDocumentFragment`/`replaceChildren`/`closest`/delegated bubbling, directly calls `deleteBtn.trigger("click")`, and asserts `elements["list"].innerHTML.includes("Vault is empty")`.
- `test/background.test.js` lines 669–700, 853, 899, 953–957, 1035, 1077, 1103, 1167–1196, 1263–1498, 1631–1632, 1703: Existing assertions index `store.series` / `patchedBody.series` by mixed-case keys (`"Solo Leveling"`, `"Chainsaw Man"`, `"Tower of God"`, etc.) and will need alignment once keys normalize to lowercase slugs.
- `test/preview/mock-chrome.js` lines 98–125 & `test/preview/mock-data.js` lines 4–61: Mock preview `SYNC_VAULT` bypasses `background.js` migration and `DELETE_SERIES` indexes `currentVault.series[mangaName]` directly on unmigrated mixed-case mock keys.

## MEMORY.md Notes
- **BUG-001** (`Google Drive History Sync`): In remote read-modify-write handlers (`background.js`), never fall back to `{ series: {} }` on `JSON.parse` errors or unexpected non-plain-object/array shapes; treat only empty (`!text.trim()`) or `404` responses as uninitialized and abort before `PATCH` while calling `setErrorBadge()`.
- **BUG-002** (`Extension Action Badge State`): Track delayed badge-clear timers (`badgeClearTimer`) at module scope in `background.js` and call `clearBadgeTimer()` before every badge state transition (`setErrorBadge`, `setInFlightBadge`, `setSuccessBadge`, `clearBadge`) so stale timers cannot clobber newer indicators.
- **BUG-003** (`Extension Popup Box-Sizing & Viewport Dimensions`): Extension popup HTML (`popup.html`) must always declare `* { box-sizing: border-box; }`, `overflow-x: hidden` on `body` (`width: 380px` for `350px` inner canvas), and `flex-wrap: wrap` on multi-item containers (`#filter-container`) to prevent horizontal scrollbars and left-edge clipping when adding controls (like Kunmanga radio and header sort toggle).
- **BUG-004** (`Offline Sync Fallback Queue`): Remote Drive helpers and `reconcileAndSync()` in `background.js` must catch errors and return structured `{ status, error }` results (calling `setErrorBadge()`) rather than throwing unhandled rejections that bypass `pending_sync` offline queuing.
- **BUG-005** (`Background-Coordinated OAuth Sync`): Keep background service-worker OAuth calls silent (`{ interactive: false }`) for passive refreshes and content-triggered syncs; pass `{ interactive: true }` only from foreground user gestures (`#refresh-btn`) or empty-cache onboarding (`!hasCachedData` in `popup.js` `loadVault()`).
- **BUG-006** (`Untrusted Web Metadata Map Keys`): Never index plain JS objects directly with untrusted DOM/URL strings; reject reserved prototype keys (`__proto__`, `constructor`, `prototype`) in `isValidMangaName()` (including normalized forms) and guard every lookup with `Object.hasOwn()`.
- **BUG-007** (`SPA Route-Change Metadata Extraction`): Never snapshot DOM-derived metadata synchronously on `window.navigation` / `history.pushState` events; `content.js` must re-run `extractPageMetadata()` after the 15s dwell settle window before dispatching `SYNC_CHAPTER`.
- **BUG-008** (`Offline Queue Re-entrancy Reconciliation`): Before an async Drive `PATCH` in `reconcileAndSync()`, snapshot `pendingQueue.length`, then re-read `pending_sync` afterward and write back `currentPending.slice(snapshotCount)`—never overwrite `pending_sync` with `[]`.
- **LESSON-001** (`MV3 Classic Script Unit Testing`): Never replace production logic with local `simulate*` helpers in tests; export real functions conditionally via `if (typeof module !== "undefined" && module.exports)` with `typeof window`/`document`/`chrome` and `typeof module === "undefined"` auto-init guards so classic MV3 scripts run in both Chrome and `node --test`.
- **LESSON-002** (`Remote / Headless Extension Live Testing`): Pair popup testing with the in-repo `test/preview/` dev harness (`server.js` on port `3456`, `index.html`, `mock-chrome.js`, `mock-data.js`) so popup UI flows can be live-verified without unpacked browser loading.
